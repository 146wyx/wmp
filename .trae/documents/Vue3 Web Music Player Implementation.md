# Vue3 Web 音乐播放器实现计划

## 项目结构
```
wmp/
├── index.html          # 入口 HTML 文件
├── main.js             # Vue 应用入口
├── App.vue             # 根组件
└── components/
    ├── MusicPlayer.vue    # 主播放器组件
    ├── Playlist.vue       # 播放列表组件
    ├── PlayerControls.vue # 播放控制组件
    └── SongInfo.vue       # 歌曲信息组件
```

## 功能特性
1. **核心播放功能**: 播放/暂停、上一首/下一首、进度条、音量控制、播放模式切换
2. **播放列表管理**: 显示歌曲列表、点击切换、当前播放高亮
3. **UI 设计**: 现代化深色主题、响应式布局、动画效果、专辑封面显示
4. **技术栈**: Vue 3 Composition API + HTML5 Audio API + CSS3

## 实现步骤
1. 创建 index.html 入口文件

3. 创建 App.vue 根组件
4. 创建 MusicPlayer.vue 主播放器组件（包含所有子组件）
5. 添加示例歌曲数据和样式
