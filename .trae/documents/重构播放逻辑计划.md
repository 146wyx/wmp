# 播放逻辑重构计划

## 1. 项目概述

当前项目是一个基于 Python HTTP Server + Vue 3 的音乐播放器，支持：
- 音乐文件存储在 SQLite 数据库中（BLOB）
- 支持 MP3、FLAC、WAV、AAC、OGG、M4A 格式
- 歌词显示（LRC 格式）
- 封面图片显示
- 播放模式：顺序播放、随机播放、单曲循环
- 用户收藏功能

## 2. 当前播放逻辑存在的问题

### 2.1 架构问题
1. **播放状态管理混乱** - 所有状态分散在组件中，没有统一的管理
2. **音频元素控制不够精细** - 缺乏对音频加载、缓冲、错误的完整处理
3. **播放历史缺失** - 没有记录播放历史的功能
4. **播放队列管理简单** - 只是简单的数组索引，缺乏队列管理

### 2.2 功能问题
1. **随机播放算法简单** - 使用 Math.random()，可能导致重复播放
2. **进度条拖动不够流畅** - 事件处理可以优化
3. **音量控制没有记忆** - 刷新后音量重置
4. **播放进度没有持久化** - 歌曲播放到一半刷新后从头开始

### 2.3 代码问题
1. **播放逻辑和 UI 耦合** - MusicPlayer.js 既管播放又管 UI
2. **缺乏播放服务层** - 没有独立的播放服务/控制器
3. **错误处理不完善** - 音频加载失败等情况处理不够

## 3. 重构目标

### 3.1 架构目标
- 建立清晰的播放服务层（PlayerService）
- 统一的状态管理（PlayerState）
- 播放逻辑与 UI 分离

### 3.2 功能目标
- 完善的播放队列管理
- 智能随机播放（不重复）
- 播放进度持久化（localStorage）
- 音量设置持久化
- 播放历史记录
- 更好的错误处理和恢复

### 3.3 性能目标
- 音频预加载机制
- 更流畅的进度条控制
- 减少不必要的重渲染

### 4.3 播放模式算法

#### 4.3.1 顺序播放 (sequence)
```javascript

```

#### 4.3.2 随机播放 (random)
```javascript
// 智能随机：不重复播放最近播放过的歌曲
function generateRandomQueue(playlist, history, maxHistorySize = 10) {
  const recentSongs = history.slice(0, maxHistorySize).map(h => h.id)
  const available = playlist.filter(s => !recentSongs.includes(s.id))
  
  // Fisher-Yates 洗牌算法
  for (let i = available.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [available[i], available[j]] = [available[j], available[i]]
  }
  
  return available
}
```

#### 4.3.3 单曲循环 (single)
```javascript
// 重复当前歌曲
onEnded = () => {
  audio.currentTime = 0
  audio.play()

```

#### 4.3.4 列表循环 (loop)

## 6. 关键技术点

### 6.1 音频预加载
```javascript
// 预加载下一首
preloadNext() {
  const nextIndex = this.getNextIndex()
  const nextSong = this.playlist[nextIndex]
  if (nextSong && !nextSong.preloaded) {
    const audio = new Audio()
    audio.src = nextSong.url
    audio.preload = 'metadata'
    nextSong.preloaded = true
  }
}
```

### 6.2 进度条平滑拖动
```javascript
// 使用 requestAnimationFrame 优化拖动
startDrag(event) {
  this.isDragging = true
  this.updateProgress(event)
  
  const onMove = (e) => {
    if (!this.isDragging) return
    requestAnimationFrame(() => this.updateProgress(e))
  }
  
  const onUp = () => {
    this.isDragging = false
    this.seek(this.currentTime)
    document.removeEventListener('mousemove', onMove)
    document.removeEventListener('mouseup', onUp)
  }
  
  document.addEventListener('mousemove', onMove)
  document.addEventListener('mouseup', onUp)
}
```
